    AWS GUIDE CORE AREAS

    COMPUTE

    - Run applications on virtual servers, containers, and managed compute

- EC2 = Elastic Compute Cloud
- ECS = Elastic Container Service
- EKS = Elastic Kubernetes Service
- Fargate
- Elastic Beanstalk
- Auto Scaling

    STORAGE

    - Store files, backups, block storage, and shared file systems

- S3 = Simple Storage Service
- EBS = Elastic Block Store
- EFS = Elastic File System
- S3 Glacier

    NETWORKING AND CONTENT DELIVERY

    - Connect resources, control traffic, DNS, and global content delivery

- VPC = Virtual Private Cloud
- Route 53
- CloudFront
- ELB = Elastic Load Balancing
- Transit Gateway
- Direct Connect

    DATABASES

    - Managed relational, NoSQL, cache, and analytics databases

- RDS = Relational Database Service
- Aurora
- DynamoDB
- ElastiCache
- Neptune
- Redshift

    SECURITY, IDENTITY AND COMPLIANCE

    - Manage users, permissions, encryption, secrets, and security

- IAM = Identity and Access Management
- IAM Identity Center
- KMS = Key Management Service
- Secrets Manager
- Cognito
- WAF = Web Application Firewall
- Shield
- GuardDuty
- Security Hub

    MONITORING, LOGGING AND OBSERVABILITY

    - Monitor applications, infrastructure, logs, and AWS activity

- CloudWatch
- CloudTrail
- X-Ray
- AWS Config

    SERVERLESS

    - Run code and applications without managing servers

- Lambda
- API Gateway
- Step Functions
- EventBridge

    CONTAINERS

    - Build, store, run, and orchestrate containers

- ECS = Elastic Container Service
- EKS = Elastic Kubernetes Service
- ECR = Elastic Container Registry
- Fargate

    DEVOPS AND DEPLOYMENT

    - Automate building, testing, deployment, and infrastructure

- CodeBuild
- CodePipeline
- CodeDeploy
- CloudFormation
- CDK = Cloud Development Kit
- Systems Manager

    MESSAGING AND INTEGRATION

    - Connect applications using queues, messages, events, and workflows

- SQS = Simple Queue Service
- SNS = Simple Notification Service
- EventBridge
- Step Functions
- Amazon MQ = Amazon Message Queuing

    DATA AND ANALYTICS

    - Collect, process, query, visualize, and analyze data

- Athena
- Glue
- Kinesis
- EMR = Elastic MapReduce
- OpenSearch
- QuickSight
- Redshift

    AI AND MACHINE LEARNING

    - Build, train, deploy, and consume AI and machine learning models

- ML = Machine Learning
- SageMaker
- Bedrock
- Rekognition
- Comprehend
- Textract
- Transcribe
- Polly

    APPLICATION INTEGRATION

    - Connect services and applications through APIs, events, and workflows

- API Gateway
- EventBridge
- Step Functions
- SQS = Simple Queue Service
- SNS = Simple Notification Service
- AppFlow

    DEVELOPER TOOLS

    - Tools for developing, testing, debugging, and managing applications

- Cloud9
- CodeArtifact
- CodeBuild
- CodeDeploy
- CodePipeline
- X-Ray

    MANAGEMENT AND GOVERNANCE

    - Manage AWS accounts, resources, policies, and organizational structure

- Organizations
- Control Tower
- CloudFormation
- Systems Manager
- Service Catalog

    MIGRATION AND DATA TRANSFER

    - Move servers, applications, databases, and data to AWS

- DMS = Database Migration Service
- Migration Hub
- Application Migration Service
- DataSync
- Transfer Family

    BACKUP AND DISASTER RECOVERY

    - Protect data and recover applications after failures

- AWS Backup
- Elastic Disaster Recovery
- S3 Glacier

    COST MANAGEMENT

    - Monitor, analyze, forecast, and optimize AWS spending

- Cost Explorer
- AWS Budgets
- Cost and Usage Reports
- Compute Optimizer

    END USER COMPUTING

    - Provide managed desktops and applications

- WorkSpaces
- AppStream 2.0

    INTERNET OF THINGS

    - Connect and manage physical devices

- IoT = Internet of Things
- IoT Core
- IoT Greengrass
- IoT Device Management

    HYBRID CLOUD AND EDGE

    - Run AWS services across on premises environments and edge locations

- Outposts
- Local Zones
- Wavelength
- Snowball
