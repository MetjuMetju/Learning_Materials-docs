### PROXY SERVERS WIDELY USED OPTIONS

### Squid
    Forward proxy / reverse proxy / cache
    Widely used for corporate Internet access,
    filtering, authentication, logging and caching

### NGINX
    Web server / reverse proxy / load balancer
    Very widely used for websites, APIs,
    TLS termination and application routing

### HAProxy
    Load balancer / reverse proxy
    Widely used for high-performance L4/L7
    traffic distribution and high availability

### Apache HTTP Server
    Web server / reverse proxy / load balancer
    Mature and extremely widely deployed,
    especially in traditional web hosting

### Traefik
    Reverse proxy / load balancer
    Very popular with Docker and Kubernetes

### Envoy
    High-performance proxy / load balancer
    Very common in Kubernetes, microservices
    and service-mesh environments

### Apache Traffic Server
    Forward/reverse proxy / cache
    High-performance proxy and caching server,
    similar territory to Squid

### Caddy
    Web server / reverse proxy
    Simple configuration and automatic HTTPS

### CLOUD / ENTERPRISE

### Cloudflare
    Reverse proxy / CDN / WAF
    Extremely widely used for public Internet
    applications and websites

### AWS ALB / ELB
    Managed load balancing / reverse proxy
    Very common in AWS environments

### GCP Cloud Load Balancing
    Managed load balancing / reverse proxy
    Very common in Google Cloud

### Azure Application Gateway / Azure Load Balancer
    Managed reverse proxy / load balancing
    Common in Microsoft Azure environments

### History

### SQUID
    1994  Harvest Object Cache project at UC San Diego
    1996  Squid became a separate project
    1998  Released under the GNU GPL
    2000s Widely adopted as an Internet forward proxy
    Today Mature open-source forward proxy/cache

### NGINX
    2002  Created by Igor Sysoev
    2004  First public release
    2010s Became widely used as a web server/reverse proxy
    Today Major web server and reverse proxy

### HAProxy
    2000  Created by Willy Tarreau
    2001  First public release
    2000s Widely adopted for load balancing
    Today Major high-performance load balancer/reverse proxy

### APACHE HTTP SERVER
    1995  First public release
    1999  Apache Software Foundation established
    2000s Dominant web server on the Internet
    Today Mature web server with reverse-proxy capabilities

### MAIN FOCUS
    Squid    → Forward proxy / caching
    NGINX    → Web server / reverse proxy
    HAProxy  → Load balancer / reverse proxy
    Apache   → Web server / reverse proxy
