# AWS GUIDE CORE AREAS

### COMPUTE

	- Run applications on virtual servers, containers, and managed compute

	- EC2 = Elastic Compute Cloud
	- ECS = Elastic Container Service
	- EKS = Elastic Kubernetes Service
	- Fargate
	- Elastic Beanstalk
	- Auto Scaling


### STORAGE

	- Store files, backups, block storage, and shared file systems

	- S3 = Simple Storage Service
	- EBS = Elastic Block Store
	- EFS = Elastic File System
	- S3 Glacier


### NETWORKING AND CONTENT DELIVERY

	- Connect resources, control traffic, DNS, and global content delivery

	- VPC = Virtual Private Cloud
	- Route 53
	- CloudFront
	- ELB = Elastic Load Balancing
	- Transit Gateway
	- Direct Connect

	- Managed relational, NoSQL, cache, and analytics databases

	- DynamoDB
	- ElastiCache
	- Neptune
	- Redshift

	- IAM = Identity and Access Management
	- IAM Identity Center
	- KMS = Key Management Service
	- Secrets Manager
	- Cognito
	- WAF = Web Application Firewall
	- Shield
	- GuardDuty
	- Security Hub


### MONITORING, LOGGING AND OBSERVABILITY

	- Monitor applications, infrastructure, logs, and AWS activity

	- CloudWatch
	- CloudTrail
	- X-Ray
	- AWS Config
