# CKA Domains & Competencies Topics

https://training.linuxfoundation.org/certification/certified-kubernetes-administrator-cka/


##### 1. STORAGE - 10%
##### 2. TROUBLESHOOTING - 30%
##### 3. WORKLOADS & SCHEDULING - 15%
##### 4. CLUSTER ARCHITECTURE, INSTALLATION & CONFIGURATION - 25%
##### 5. SERVICES & NETWORKING - 20%

##### 1. STORAGE - 10%

    1. Implement storage classes and dynamic volume provisioning
    2. Configure volume types, access modes and reclaim policies
    3. Manage persistent volumes and persistent volume claims

##### 2. TROUBLESHOOTING - 30%

    4. Troubleshoot clusters and nodes
    5. Troubleshoot cluster components
    6. Monitor cluster and application resource usage
    7. Manage and evaluate container output streams
    8. Troubleshoot services and networking

##### 3. WORKLOADS & SCHEDULING - 15%

    9. Understand application deployments and rolling updates/rollbacks
    10. Use ConfigMaps and Secrets to configure applications
    11. Configure workload autoscaling
    12. Understand primitives for robust, self-healing applications
    13. Configure Pod admission and scheduling (limits, node affinity, etc.)

##### 4. CLUSTER ARCHITECTURE, INSTALLATION & CONFIGURATION - 25%

    14. Manage role-based access control (RBAC)
    15. Prepare infrastructure for installing a Kubernetes cluster
    16. Create and manage Kubernetes clusters using kubeadm
    17. Manage the lifecycle of Kubernetes clusters
    18. Implement and configure a highly available control plane
    19. Use Helm and Kustomize to install cluster components
    20. Understand extension interfaces (CNI, CSI, CRI, etc.)
    21. Understand CRDs, install and configure operators

##### 5. SERVICES & NETWORKING - 20%

    22. Understand connectivity between Pods
    23. Define and enforce Network Policies
    24. Use ClusterIP, NodePort, LoadBalancer service types and endpoints
    25. Use the Gateway API to manage Ingress traffic
    26. Know how to use Ingress controllers and Ingress resources
    27. Understand and use CoreDNS
